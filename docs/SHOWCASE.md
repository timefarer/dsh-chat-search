# 功能演示：会话搜索 × 全局搜索

> `dsh-chat-search` 给 DeepSeek Harness 加了**两种检索入口、一套结果模型**：
> 右侧栏管"这段对话我说过什么"，左侧栏管"我所有对话里说过什么"。
> 两边都能搜到**段落**和**文件名**，点一下就能跳到原文，并把命中词留在屏幕上。

本文是给 README/发布页用的演示稿：先看两个入口，再看五个真实场景，最后是边界与上手。
文中结果树为示意，实际条数取决于你的会话。

---

## 1. 两个入口，一张地图

```
左侧导航              主内容区                        右侧栏
────────              ────────────────────────        ────────────────
对话                  会话标题栏   [🔍] ← 打开检索      对话检索
▸ 全局搜索 ─────────▶ 提问 / 回复（命中词高亮）        第 3 轮 · 3 处
                      跳转落点 + 蒙版过场              回复 · 第 2 段 · 3 处
                                                       文件 · client.js
```

| 入口 | 触发方式 | 检索对象 | 适合 |
|---|---|---|---|
| **会话搜索** | 会话标题栏放大镜 / `Ctrl+F`（macOS `⌘F`） | 当前对话（自动补全未加载的历史） | "刚才那句结论在哪一段？" |
| **全局搜索** | 左侧导航「全局搜索」 | 所有已存储会话 | "上周那次评审我到底怎么定的？" |

两者共用同一套 **会话 → 问题 → 段落** 结果模型和同一套跳转/高亮实现，
所以学会一个，另一个看结果树的形状就懂了。

---

## 2. 会话搜索：在当前对话里找一句话

**打开**：点标题栏的放大镜，或直接 `Ctrl/Cmd+F`。面板落在右侧栏，输入框自动获得焦点。

**输入**：边打边搜（140ms 防抖）。多个关键词用空格分隔，**全部出现**才算命中；
中文按子串匹配，大小写不敏感。

**结果**：按对话轮次分组，组头是「第 N 轮 + 你的提问」，每条结果一行：

```
第 3 轮   这个插件的结果为什么按三层展开？
  回复 · 第 2 段 · 3 处    …结果按 会话 → 问题 → 段落 三层展开，文件名也是可检索项…
  回复 · 第 7 段           …高亮用 ::highlight()，滚动时天然跟随…
  回复 · 文件              client.js
```

- 行首是 **角色（提问/回复）· 第 N 段**，命中次数大于 1 时才追加 `· N 处`；
  后面跟着带高亮的三行摘要；
- 消息没有正文、只有附件或工具调用时，会出现**文件行**，文件名本身可被检索；
- 组头就是这一轮的提问，所以扫一眼就知道"这句话是在回答什么"。

**点击**：滚动到对应消息，命中词用浏览器查找式底色标出，**滚动跟随、直到下一次检索**才消失。
目标消息还没加载？面板会先补历史（显示"更早的历史尚未加载 / 加载全部"），再定位。

**键盘**：`Enter` 跳到第一条，`↑/↓` 在结果间走，`Esc` 清空。`Ctrl/Cmd+F` 在面板打开时再次按下会聚焦输入框。

**记忆**：同一次运行内，每个会话记住上次查询词，切回来不用重打。

### 多轮对话：按"哪一次讨论"分组

同一个词在一次长对话里会反复出现。面板不按时间平铺，而是按轮次分组，组头就是那一轮的提问——
你可以只看「第 4 轮」那组，跳过早期的试错：

```
第 1 轮   我想在右侧栏加一个检索框，能搜当前对话就行
  回复 · 第 2 段 · 2 处    …先接 useChat 的节点，零网络、随输入即时应答…
第 3 轮   跳转总是停在上一条消息，怎么办
  提问 · 第 1 段           …跳转总是停在上一条消息…
  回复 · 第 4 段 · 5 处    …用 seq 精确匹配，找不到再 loadThrough 补历史…
第 4 轮   把 README 和版本号收一下
  回复 · 第 1 段           …README 补一段安装说明…
  回复 · 文件              README.md
```

- 轮次号是**会话内真实序号**：「最近 N 轮」裁掉早期轮次后，第一组可能直接从「第 7 轮」开始，**不重新编号**；
- 跳转用的也是这个序号，所以筛选只影响"显示哪些"，不影响"跳到哪"。

## 3. 全局搜索：在所有会话里找一件事

**打开**：左侧导航「全局搜索」，占满主内容区，不是浮层。

**五个检索范围**（默认第一个）：

| 范围 | 匹配字段 |
|---|---|
| 会话 + 问题 + 段落（默认） | 标题、提问文本与附件名、回复段落与工具调用文件名 |
| 会话 + 问题 | 只到"提问"这一层 |
| 仅会话 | 只匹配会话标题，文件不参与 |
| 仅问题 | 只匹配你问过的话 |
| 仅段落 | 只匹配回复正文 |

**结果树**：会话 → 问题（第 N 轮）→ 段落（第 N 段；命中多于 1 处时追加 `· N 处`），逐层展开：

```
▾ 对话检索 · 段落与文件名检索（示意）       3 个会话 · 4 个问题 · 12 个段落 · 86ms
    ▾ dsh-chat-search：会话搜索插件的设计取舍      标题命中 · 2 问 · 9 段   [打开会话]
        第 3 轮  这个插件的结果为什么按三层展开？   问题命中
            第 2 段 · 3 处   …结果按 会话 → 问题 → 段落 三层展开…
                    输入：README.md      输出：docs/FEATURES.md
            第 7 段          …高亮用 ::highlight()，滚动时天然跟随…
```

- 命中位置**就地高亮**：标题、问题、段落各自标出自己的命中词；
- 文件以胶囊显示，区分 **输入**（你附上的文件）与 **输出**（工具写过/读过的路径、`apply_patch` 头）；
- 默认展开前 2 个会话，顶部有「全部展开 / 全部收起」；
- 每个会话行有「打开会话」；问题/段落行点一下直接**打开 + 定位**。

**空结果时**不会只回一句"没找到"：如果当前不是全范围，会给「在全部范围中搜索」；
日期/轮次筛选收得太紧，也会提示放宽。

**其他**：`最近搜索` 保留最近 8 条（Host 持久化，重启还在）；`刷新索引` 绕过 30s 缓存强制重建；
底部统计行给出 `N 个会话 · N 个问题 · N 个段落 · N ms`；`Enter` 检索，`↓` 进结果，`↑/↓` 移动，`Esc` 清空。

## 4. 筛选窗口：给检索划一个时间与轮次的框

会话搜索和全局搜索共用一套窗口，输入框下方一行「筛选 · 最近 14 天 · 30 轮」，点开即编辑：

| 维度 | 默认 | 留空 / 0 | 语义 |
|---|---|---|---|
| 日期范围 | 最近 14 天（含今天） | 该端不限 | 按**轮次时间**过滤，不是会话创建时间 |
| 最近 N 轮 | 30 | 不限 | 每个会话只取最后 N 轮，再按日期过滤 |

- 摘要行直接写成 `10-27 ~ 11-09 · 最近 30 轮`，全部不限时显示 `全部范围`；
- 改完**立即重跑**当前检索，不用重新输入关键词；
- 写入 `plugin-data/conversation-search/filters.json`，下次启动沿用；
- 「重置」一键回到 14 天 / 30 轮。

> 注意：筛选减少的是匹配与返回的工作量，索引仍要读一遍会话日志——宿主没有暴露"某会话最后一次写入时间"。

## 5. 点一下就到：跳转与高亮

搜索结果最怕"跳是跳了，但停在隔壁"。这里的落地顺序是：

1. 用 `seq` 找**精确节点**；
2. 找不到就找**同一轮**里文本包含锚点的节点；
3. 再找**任意节点**包含锚点的；
4. 只有在历史已全部加载、或重试超限时，才退到"最近节点"；
5. 都不中就不落点，先 `loadThrough(seq)` 补历史，再继续等。

落地后用浏览器的原生 `::highlight()` 给命中词上底色（无边框、纯文字标记），
并在 120/400/900/1500ms 重放一次，抵消平滑滚动和重渲染带来的坐标漂移。
打开长会话时会有全窗口蒙版（160ms 后才出现，避免闪一下），落地即撤，20s 硬超时兜底。

## 6. 五个真实用法

**① "上周那次评审我到底怎么定的？"**
全局搜索 → 关键词 `评审 结论` → 日期改成上周 → 结果直接落在那次会话的第 N 轮。
不用记是哪个会话，时间窗口先帮你把范围砍到一周。

**② "我改过哪个文件？"**
搜 `DESIGN.md` 或 `client.js`。文件名是独立结果行，工具调用路径、`apply_patch` 头都在索引里，
所以"文件名记得，正文忘了"也能找回来。

**③ "当初为什么用 ::highlight 而不是画框？"**
全局搜索范围切到「仅段落」，搜 `高亮` → 直接点到 DESIGN 文档那段说明，命中词常驻，边滚边看上下文。

**④ "这个坑我在别的项目里是不是也踩过？"**
范围切到「仅问题」，把范围放大到全部时间，搜报错关键词。
只匹配提问，能避开回复里大量重复的解释文本。

**⑤ "交接：把某个会话里所有涉及配置的段落捞出来"**
会话搜索打开，搜 `配置 env`（两个词都要出现），按轮次分组浏览，点进任意一条就能回到原话。

## 7. 能力边界（先说清楚，免得误会）

- **只读本地**：走 Host 的 `sessionQuery`，不发任何网络请求；HTTP 路由没有浏览器凭据直接 401。
- **规模上限**：索引最多 400 个会话 / 800 万字符；单次响应最多 30 会话 × 12 问题 × 8 段落，超出标 `truncated`，不翻页。
- **索引新鲜度**：30s TTL，live 事件数变化即时失效，2.5s 最小重建间隔；必要时点「刷新索引」。
- **不支持**：正则、文件正文检索（只索引会话触及的文件名）、跨会话的"注入上下文"开关。
- **文件检索的边界**：会话附件 + 工具调用路径 + patch 头；工作区里没被会话碰过的文件不在索引里。
- **依赖宿主 DOM 锚点**：`data-chat-node-key` / `data-chat-flow` 这类未公开锚点，DSH 大版本升级可能失效。

## 8. 30 秒上手

**应用内安装（推荐）**：DSH → **插件** 页 → **添加插件** → 搜索 `dsh-chat-search` → **安装**。

**命令行**：

```sh
dsh plugin add dsh-chat-search

# 指定 profile 时
dsh plugin --profile desktop add dsh-chat-search

# 从源码（开发时）
dsh plugin add link:<本目录>
```

安装后**完全退出并重开 DSH**（Host 半区只在进程启动时加载一次，刷新页面不够），然后：

1. `Ctrl/Cmd+F` → 搜 `高亮` → 点第一条，看它跳过去并标出命中词；
2. 左栏「全局搜索」→ 搜 `conversation-search` → 打开任意会话行；
3. 把筛选改成「最近 3 天 · 10 轮」→ 看结果树怎么缩。

更多实现细节见 [DESIGN.md](./DESIGN.md)，功能清单见 [FEATURES.md](./FEATURES.md)。
