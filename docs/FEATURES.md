# 功能清单

## 一、会话内检索（右侧栏）

| 功能 | 说明 |
|---|---|
| 打开方式 | 会话标题栏放大镜按钮；Ctrl/Cmd+F 快捷键 |
| 输入 | 实时检索（140ms 防抖），空格分隔多关键词（AND） |
| 结果分组 | 按 DSH 的 Turn 分组，组头显示「第 N 轮 + 该轮首个提问摘要」；轮次号与全局页同源 |
| 结果条目 | `角色（提问/回复） · 第 M 段 · 命中次数` + 三行摘要，命中词高亮；段落号在一个 Turn 内跨回复消息连续 |
| 文件行 | 无正文但有文件的消息显示为「文件」行，文件名可命中 |
| 点击跳转 | 滚动到对应消息 + 命中词文字高亮（浏览器查找效果，跟随滚动）；目标段落另有蓝色选中底色 |
| 全局补开 | 从全局跳转打开本面板若来不及挂载，会话 open 后自动补开（最长 10 秒），面板出现即确认 |
| 键盘 | Enter 跳第一条；↑/↓ 在结果间移动；Esc 清空 |
| 历史补全 | 输入非空且历史未加载完时自动分页补齐（同一面板一次） |
| 进度提示 | 未加载完时显示「更早的历史尚未加载」与进度 |
| 记忆 | 每个会话记住上次查询词（页面生命周期内） |
| 范围 | 有查询时显示「全部 / 仅问题 / 仅段落」三档，切换即重搜 |
| 全局联动 | 从全局结果跳转进来时，自动带上同一关键词、同一筛选窗口与映射后的范围，并落在同一段 |
| 筛选窗口 | 输入框下方一行「筛选 · 最近 14 天 · 30 轮」，点击展开日期/轮次编辑 |

## 一·五、筛选窗口（两处共用）

| 功能 | 说明 |
|---|---|
| 日期范围 | 开始 / 结束两个日期；默认最近 14 天（含今天）；任一留空即该端不限 |
| 对话轮次 | 「最近 N 轮」，默认 30；留空或 0 即不限 |
| 重置 | 一键恢复默认（14 天 / 30 轮） |
| 摘要 | 面板按钮与全局页统计行显示当前窗口，如 `10-27 ~ 11-09 · 最近 30 轮`；全部不限显示 `全部范围` |
| 生效范围 | 全局检索对**每个会话**裁剪；会话内检索只作用于**当前会话** |
| 即时生效 | 改动筛选后自动重跑当前检索，无需重新输入关键词 |
| 持久化 | 写入 `plugin-data/conversation-search/filters.json`，重启后沿用 |
| 轮次语义 | 先取会话最后 N 轮，再按日期过滤；结果中的「第 N 轮」仍是会话内的真实序号 |

## 二、全局检索（左侧栏 → 主内容区）

| 功能 | 说明 |
|---|---|
| 入口 | 左侧导航「全局搜索」图标（order 5） |
| 检索范围 | 会话+问题+段落（默认）/ 会话+问题 / 仅会话 / 仅问题 / 仅段落 |
| 轮次编号 | 与 DSH 的 Turn 号一致；同一 Turn 的多条用户消息合并为一条问题；没有用户消息的 Turn 也可检索 |
| 结果树 | 会话 → 问题（含输入文件胶囊）→ 段落（含输出文件胶囊） |
| 命中解释 | 会话标题、问题文本、文件名分别就地高亮；文件行显示文件胶囊 |
| 打开 | 「打开」按钮打开会话；问题/段落行打开并定位 |
| 展开控制 | 默认展开前 2 个会话；全部展开 / 全部收起 |
| 刷新索引 | 强制 Host 重建语料（绕过 30s 缓存） |
| 放宽范围 | 空结果且非全范围时提供「在全部范围中搜索」 |
| 最近搜索 | 显示最近 8 条（Host 持久化），点击重查 |
| 键盘 | Enter 立即检索；↓ 进入结果；↑/↓ 移动；Esc 清空 |
| 状态 | 空闲提示、检索中、空结果、错误 + 重试 |

## 三、跳转与过场

| 功能 | 说明 |
|---|---|
| 过场蒙版 | 全窗口遮罩 + 转圈 + 会话标题；160ms 后才出现，避免闪烁 |
| 结束条件 | 有跳转：落地或放弃；无跳转：会话 open / error；20s 硬超时 |
| 落点解析 | seq 精确 → 同轮文本锚点 → 任意文本锚点 → （历史加载完或重试超限）最近节点 |
| 历史补齐 | 未命中目标时调用 `loadThrough(seq)`，不提前落点 |
| 落地标记 | 120/400/900/1500ms 重放滚动 + 命中词高亮 + 段落选中 |
| 段落选中 | 目标段落覆盖蓝色底色 `::highlight(dsh-chat-search-selected)`（`rgba(74,144,255,.18)`），琥珀关键词压在其上；无 API 时给块元素描边 |
| 高亮样式 | 原生 `::highlight()`（纯文字底色、无边框、跟随滚动）；无该 API 时退化为跟随滚动的方框，并按对话滚动容器与输入框底座裁剪，越界隐藏 |

## 四、检索语义

| 功能 | 说明 |
|---|---|
| 匹配 | 大小写不敏感子串；关键词全部出现 |
| 分段 | 消息按空行切分段落，块间插入空行 |
| 范围隔离 | 「仅会话」只匹配标题，文件不参与 |
| 文件来源 | 用户附件（`attachment.name`）、工具参数路径、`apply_patch` 头 |
| 过滤 | 排除 URL、含空白/换行的值；单消息最多 6 个文件名 |
| 去重 | 正文已含文件名时不再生成文件行；同名文件只保留一次 |

## 五、数据与运维

| 功能 | 说明 |
|---|---|
| 语料索引 | `ctx.sessionQuery` 全量会话，实时优先、持久化兜底；按 `turn/start` 的 Turn 号归并，无该事件的旧日志回退用户消息序号 |
| 缓存 | 30s TTL；live 事件数变化即时失效；2.5s 最小重建间隔 |
| 预算 | 400 会话 / 800 万字符 / 单会话 3 万事件 |
| 响应上限 | 30 会话 / 12 问题 / 8 段落 / 150 字片段 |
| 历史文件 | `<profile>/plugin-data/conversation-search/recent.json`（原子写） |
| 鉴权 | `ctx.connection.requestRejection`，无凭据 401 |
| 失败降级 | 索引读取失败跳过该会话；历史读写失败退回内存；检索异常返回 500 信封 |

## 六、界面与可访问性

| 功能 | 说明 |
|---|---|
| 主题 | 仅使用 `--dsw-alias-*` / `--dsw-specific-*` 令牌，跟随明暗主题 |
| 语言 | 中文 / English 两套文案 |
| 语义 | `role="status"`（蒙版）、`aria-expanded`（折叠行）、`aria-checked`（范围胶囊） |
| 焦点 | 面板打开自动聚焦；快捷键聚焦任意可见面板 |
| 动效 | 尊重 `prefers-reduced-motion`（滚动改为即时） |
