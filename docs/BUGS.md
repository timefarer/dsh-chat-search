# 缺陷列表

状态：✅ 已修复 · 🟡 已缓解 · ⏳ 待修

**编号约定**：`B` = 缺陷（Bug），`K` = 已知问题（Known）；「来源」列区分反馈与自测。

| ID | 来源 | 现象 | 根因 | 修复 | 状态 |
|---|---|---|---|---|---|
| B1 | 反馈 | 全局结果点「打开会话」无反应 | 用 `ctx.uiWorkspace` / `ctx.layout` 属性取服务，插件未注入这些服务，读到 `undefined` 被静默跳过；且会话面板应通过 `selectPanel(null)` 切回 | 改用 `ctx.get('uiWorkspace')` 调 `openSession`，由其内部完成面板切换；缺失时打印错误 | ✅ |
| B2 | 反馈 | 结果层级不明显、信息混乱 | 单行平铺，徽标+计数+路径挤在一行，命中原因不可见 | 三层卡片结构；标题/问题/文件就地高亮；计数收敛为胶囊；缩进 + 左侧竖线 | ✅ |
| B3 | 反馈 | 打开后要等一段才跳，蒙版提前消失 | 蒙版在 `openState === 'open'` 结束，而跳转发生在其后 | 有跳转时仅由落地/放弃结束蒙版；超时 20s | ✅ |
| B4 | 反馈 | 全局跳转落点不准 | `keyNear` 找不到精确 seq 时直接返回「最近已加载节点」并删除待办跳转，目标未加载时先跳到上一条且不再纠正 | `anchor + turn` 优先解析；未命中先 `loadThrough`；仅历史加载完或重试超限才允许最近兜底 | ✅ |
| B5 | 反馈 | 搜索历史重启后消失 | 仅存于模块级数组 | Host 落盘 `recent.json`，搜索响应回传，页面初次加载拉取 | ✅ |
| B6 | 反馈 | 搜不到文件名 | 文件名只用于展示，从未参与匹配；附件名从错误层级读取；只认写类工具 | 附件名读 `block.attachment`；所有工具路径 + patch 头；文件名参与问题/段落匹配 | ✅ |
| B7 | 反馈 | 跳转后内容区没有高亮 | `::highlight()` 规则里用了 `color-mix()`，不支持的构建会丢弃该声明，高亮"存在但透明"；Range 还会被重渲染替换 | 颜色一律先用 `rgba()`；原生高亮为首选，几何覆盖层仅作兜底；落地后重放 4 次 | ✅ |
| B16 | 反馈 | 高亮方框不跟随滚动，观感像浮层图标 | 覆盖层用视口坐标一次绘制，滚动后不更新 | 改为**原生 `::highlight` 优先**（锚定文本、天然跟随滚动）；无 API 时兜底方框监听滚动 + rAF 重定位 | ✅ |
| B17 | 反馈 | 高亮区域有边框、且几秒后消失 | 兜底方框带 1px `box-shadow`；落地时给整行加了描边环；高亮设了 4.6s 定时清除 | 去掉方框描边与整行描边环；高亮改为**常驻**，仅在查询变化或关闭会话内检索面板时清除 | ✅ |
| B14 | 反馈 | 会话内面板跳转后仍看不到高亮 | 面板路径只调 `jumpToNode` 一次，方框画在**平滑滚动前**的坐标上，滚动后留在旧位置 | `jumpToNode` 内部统一为「立即绘制 + 120/400/900/1500ms 重放」，两条跳转路径共用 | ✅ |
| B15 | 反馈 | 长段落（含换行）按锚点匹配失败，退化为就近节点 | 锚点由 Host 归一化（空白折叠），节点文本未归一化，`includes` 对不上 | `nodeTextOf` 同样折叠空白并 trim；锚点匹配限定在目标角色节点内 | ✅ |
| B18 | 反馈 | 改名后跳转完全没有高亮，无任何报错 | `HIGHLIGHT` 常量改成 `dsh-chat-search`，但注入的 `::highlight()` 选择器仍写旧名，两者不匹配，高亮「存在但透明」 | 选择器与常量统一；测试新增断言「CSS 选择器 == 插件导出的 highlight 名」 | ✅ |
| B19 | 反馈 | 全局检索的「第 N 轮」与会话内面板不一致 | 全局按问题数组序号（`turnIndex+1`）编号，面板用 DSH 的 Turn 号；同一 Turn 里出现第二条用户消息、或某轮没有用户消息时，后续整体错位（实测本机语料两者都出现过） | Host 改用 `turn/start` 的 `data.turn`；同轮多条用户消息合并为一条问题；无用户消息的 Turn 也能检索；无 `turn/start` 的旧日志回退旧编号 | ✅ |
| B20 | 反馈 | 全局跳转后段落数值不对（或怀疑没加载完） | 全局把一轮内所有回复消息的段落连续累计，面板按单条消息从 1 编号；镜像检索还用面板自己的筛选窗口 | 面板按 Turn 累计偏移、段落号跨消息连续；镜像检索带上全局当前的筛选窗口；跳转前已 `loadThrough` 到目标 | ✅ |
| B21 | 反馈 | 高亮偶尔出现在输入框上方 | 无 Custom Highlight API 时的兜底覆盖层是 body 级 `position: fixed` 框，只按视口坐标绘制，不按对话滚动容器与输入框底座裁剪 | 按 `[data-conversation-scroll]` 与 `[data-composer-seat]` 裁剪：越界隐藏、部分可见裁切；ResizeObserver 重算；插件加载时清理遗留层 | ✅ |
| B22 | 反馈 | 从全局跳转偶尔不打开会话搜索面板 | `openSession` 后立刻开 tab，只重试 6×180ms；跨会话切换会重挂右栏，早开的那次被重置后即放弃 | 会话进入 `open` 后由 `PanelOpener` 再开一次；重试截止延长到 10s；面板挂载才确认完成 | ✅ |
| B23 | 反馈 | 1.2.0 之后全局与会话内的「第 M 段」仍差 1 | Host 给每个只有工具调用的步骤补一行**文件段落**，面板每条消息只补一行，两侧的行数不同，段落号整体偏移 | 两侧都不给文件行编号（`index: 0`，界面显示「文件」）；文本段落号只数文本；Host 与面板各加断言 | ✅ |
| B24 | 反馈 | 跳到目标段落后看不到蓝色选中 | 锚点取自消息**原文**（`**筛选窗口**`），对话 DOM 是**渲染后**文本（`筛选窗口`），`indexOf` 必然落空，选中静默失败 | 比较前去掉行内 markdown（粗体/斜体/行内代码/链接/删除线）；长锚点逐级缩短前缀重试；兜底块匹配同样归一 | ✅ |
| B25 | 反馈 | 对话内容区的选中有时没有、有时描边、有时描边加底色；会话内面板结果行完全没有选中态 | 选中同时存在两条路径（原生 `::highlight` 区间 / 块级描边），哪条成功取决于文本匹配，故观感不稳定；面板结果行没有记录「上次点开的行」 | 选中收敛为单一机制（块级标记 + 淡蓝底 + 内描边）；面板与全局页共用「已选中」样式，全局跳转镜像时按锚点前缀标出落点行 | ✅ |
| B8 | 反馈 | 开合会话搜索时内容区展开/收起有卡顿 | 右栏列宽变化导致中央列重排；插件自身在动画期间还有模糊合成、离屏结果布局、整树重渲染 | 移除蒙版 `backdrop-filter`；结果行/会话块 `content-visibility: auto`；全局树记忆化；面板列表保持轻量 | 🟡 宿主列宽动画仍在，只消除了本插件开销 |
| B9 | 自测 | 无标题会话在结果里显示空白 | 只取 `session/title` 事件 | Host 生成 `displayTitle`（首条提问前 40 字），仅用于展示，不参与会话层匹配 | ✅ |
| B10 | 自测 | 目标消息未加载时跳转组件空转 | 只在 `key === null` 时补历史，而就近兜底几乎从不返回 null | 未精确命中即补历史，此后每 8 次重试补一次 | ✅ |
| B11 | 自测 | 历史写入与响应不同步 | `remember` 未等待写入完成就返回 | `await writing` 后再返回 | ✅ |
| B12 | 自测 | 文件行与正文重复 | 正文已含文件名时仍生成文件行 | 正文包含全部文件名时跳过文件行 | ✅ |
| B13 | 反馈 | 高亮覆盖层可能滞留在错误位置 | 覆盖层按视口坐标绘制，用户滚动后不跟随 | 3.2s 自动淡出 + 落地重放；滚动期间最多滞留数秒 | 🟡 可接受，未做滚动跟随 |
