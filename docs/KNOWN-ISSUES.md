# 已知问题与限制

## 检索与结果

| 限制 | 说明 |
|---|---|
| **结果有上限** | 全局页最多显示 200 条匹配；超出会在结果顶部提示"仅显示前 N 条"。 |
| **语料有上限** | 最多索引 400 个会话、约 800 万字符；超出部分不参与检索，且目前没有界面提示覆盖率。 |
| **只搜已加载的历史（会话内）** | 会话内面板默认只覆盖已加载的窗口；更早的内容会在你点击结果时按需加载，顶部显示「正在加载到该段落 · 第 N 页」。 |
| **默认窗口是相对的** | 默认最近 14 天 / 每会话最近 30 轮；手动改过日期或轮次后，窗口固定，不再自动跟随今天。 |
| **中文按子串匹配** | 不做分词或全文索引：输入"筛选"能命中"筛选窗口"，但不会做同义词或拼音匹配。 |

## 跳转与高亮

| 限制 | 说明 |
|---|---|
| **折叠分组内的目标** | 目标段落位于折叠的步骤/工具分组里时，只能滚到消息并给出落点标识，不会自动展开分组。 |
| **超长历史首次跳转** | 目标在很靠前的位置时，需要先把历史加载到该位置，等待时间随距离增长。 |
| **落点标识是左侧蓝条** | 对话区只在段落左侧显示蓝色竖条；不提供整段底色或描边。 |

## 环境与兼容

| 限制 | 说明 |
|---|---|
| **依赖 DSH 内部锚点** | 插件用到少量未公开的 DOM 锚点与客户端服务；DSH 升级后可能失效，通常会在新版本跟进。 |
| **快捷键可在设置里改** | 路径：`设置 → 通用设置 → 快捷键`。插件注册两条：`在对话框中查找`（`Ctrl/Cmd+F`）与 `全局搜索（所有会话）`（默认 `Ctrl/Cmd+Alt+Q`）。 |
| **扩展快捷键排在核心命令之后** | 宿主的排序规则：核心命令按固定产品顺序，插件命令接在核心命令之后、按命令 ID 排序——排名不可由插件指定。 |
| **默认键被占用时会自动换键** | 若 `Ctrl/Cmd+Alt+Q` 已被其它插件占用，插件会顺延到下一个可用组合，并在面板顶部提示当前使用的键。 |
| **快捷键可能与输入法冲突** | 中国区输入法常占用 `Ctrl+Shift+…`，因此全局检索不使用 `Ctrl+Shift+F`。 |
| **右侧页签用 `Ctrl+W` 关闭** | 该快捷键与提示由宿主统一提供，插件不改。 |
| **首次索引需要等待** | 语料较大时，冷启动第一次搜索需要建立索引，可能等待数秒。 |

## 数据与隐私

| 说明 |
|---|
| 所有检索都在本机完成：Host 读取本机会话日志，插件不上传任何内容。 |
| 插件只在本机保存两类小文件：最近搜索（8 条）与筛选窗口设置。位置在 DSH 的 profile 数据目录下（`conversation-search/`）。 |
